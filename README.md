## Requisitos

- Windows 10/11
- PowerShell 5.1+
- Instalador: install\install-spark.ps1

## Arranque

- .\install\install-spark.ps1
- .\install\run.ps1

- install\ scripts de instalación y verificación

- notebooks\ demos
- docs\ informe y fuentes
